AEGIS-SIM 2.5 / Windows x64 portfolio release

No SDK or separately installed .NET runtime is required.
Extract the complete ZIP to a writable folder before launching.

Start-Local.cmd: local app with automatic SQLite history.
Start-Seeded-Demo.cmd: two completed runs and sample reports already prepared.
Start-Multiplayer.cmd: local host + controller + read-only observer.

Optional per-user installation:
powershell -ExecutionPolicy Bypass -File .\Install.ps1
Close earlier copies before installing again. No administrator rights required.

Saved runs: %LOCALAPPDATA%\AEGIS-SIM\local\runs.db
Host data/credentials: %LOCALAPPDATA%\AEGIS-SIM\host
Do not share session-secrets.json. This host accepts loopback connections only.
Controller Reset starts a new shared network exercise and preserves earlier saved runs.

Reports: choose Export report to save verified PDF, HTML and CSV.
PDF uses English/ASCII labels; UTF-8 HTML/CSV preserve international text.
Saved runs / A/B: select a run for replay, or Ctrl+select two runs to compare.
Reset starts a new run and preserves saved history.

See docs/demo-script.md, docs/verification.md and docs/learning/ for more.
This is a synthetic civilian training portfolio MVP, not a production operational system.

Stock + travel demo: finite depot stock and vehicle travel/return ticks.
See docs/learning/10-stock-travel.bn.md.

Tools menu: offline GeoJSON layers, completion preview and diagnostics export.
Open assets/maps/synthetic-region.geojson in the GeoJSON viewer.
Imported layers are view-only; simulation coordinates remain synthetic local meters.

Tools / Scenario editor: local draft, validation, JSON/XML save and start as a new run.
